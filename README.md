# MyZoom

연수·수업·영상 제작 때 화면을 **확대하고, 그 위에 판서하고, 발표를 보조**하는 개인용 Windows 프로그램.
ZoomIt 의 기능을 기본으로, 다른 줌·판서 도구(Epic Pen, gInk, PointerFocus, Presentify 등)에서 쓸모 있던 기능을 모아 한국어로 만들었다.

## 설치

[GitHub 릴리즈](https://github.com/uts1002/myzoom/releases/latest)에서 **`MyZoom-Setup.cmd`** 를 받아 더블클릭한다. (관리자 권한·.NET 설치 필요 없음)
최신 `MyZoom.exe` 를 받아 이 사용자에게 설치한다. `MyZoom.exe` 를 직접 받아 더블클릭해도 "설치할까요?"를 묻는다.

- 설치 위치: `%LOCALAPPDATA%\Programs\MyZoom\MyZoom.exe`
- 시작 메뉴·바탕화면 바로가기, Windows 시작 시 자동 실행, **설정 > 앱 > 설치된 앱** 목록에 등록된다
- **자동 업데이트:** 켜고 30초 뒤, 그 뒤 6시간마다 새 버전을 확인해 받아 둔다. 줌·그리기·타이머를 쓰지 않을 때 잠깐 다시 시작하며 바뀐다.
  설정 > 일반에서 끄거나 "지금 업데이트 확인"을 누를 수 있다
- 제거: 설정 > 앱 > 설치된 앱 > MyZoom > 제거 (설정까지 지울지 물어봄)
- 브라우저에서 받은 exe 는 서명이 없어 "Windows의 PC 보호" 경고가 뜰 수 있다 → 「추가 정보 → 실행」. `MyZoom-Setup.cmd` 로 설치하면 이 경고가 덜하다

### 새 버전 내보내기 (개발)

코드를 커밋한 뒤 `.\release.ps1 1.2.0 "바뀐 내용"` → `v1.2.0` 태그가 올라가고 GitHub Actions 가 빌드해 릴리즈를 만든다(3~5분).
설치된 MyZoom 들은 알아서 그 버전으로 바뀐다. 직접 빌드한 개발판(버전 0.0.0)은 자동 업데이트하지 않는다.
이 PC 에 소스로 바로 설치하려면 `install.bat` (.NET 9 SDK 필요).

원격 데스크톱으로 발표할 때는 원격 PC가 아니라 **내 앞 PC(노트북)에 MyZoom 을 켜 두고** 확대한다. 원격 PC에서 확대하면 바뀐 화면 전체를 다시 보내야 해서 끊긴다.
원격 데스크톱 연결 → 옵션 표시 → 로컬 리소스 → 「Windows 키 조합 적용」을 「이 컴퓨터」로 두면 원격 창이 앞에 있어도 노트북 쪽 단축키가 먹을 가능성이 높다(미리 눌러 볼 것).

실행되면 작업 표시줄 오른쪽 아래 트레이에 돋보기 아이콘이 생긴다. 아이콘을 두 번 누르면 설정, 오른쪽 클릭하면 모든 기능 메뉴.

## 기능과 기본 단축키

| 단축키 | 기능 | 설명 |
|---|---|---|
| Ctrl+1 | 화면 확대 | 화면을 멈추고 확대. 마우스를 따라 화면이 움직이고 휠로 배율 조절. 클릭하면 그 자리에서 판서 |
| Ctrl+2 | 그리기 | 화면을 멈추고 판서 (펜·형광펜·직선·화살표·사각형·원·글자·지우개) |
| Ctrl+Shift+2 | 화면 위에 그리기 | 화면을 멈추지 않고 그 위에 판서. 한 번 더 누르면 그림은 남긴 채 아래 프로그램 조작 |
| Ctrl+3 | 타이머 | 쉬는 시간·활동 시간 카운트다운. 흐린 화면/검정/흰 배경, 작은 창 모드 |
| Ctrl+4 | 라이브 줌 | 움직이는 화면을 그대로 확대 (클릭·입력 가능). 휠로 배율 (설정에서 Ctrl+휠로 변경 가능) |
| Ctrl+5 | 스포트라이트 | 커서 주변만 밝게, 나머지 어둡게. Ctrl+휠로 크기 |
| Ctrl+6 | 영역 캡처 | 드래그한 영역을 클립보드로 (선택하면 파일로도 저장) |
| Ctrl+7 | 커서·클릭 강조 | 커서 둘레 색 원 + 클릭할 때 퍼지는 고리 (녹화용) |
| Ctrl+8 | 키 입력 표시 | 누른 단축키를 화면 아래에 표시 (녹화용, 기본은 단축키만) |

모든 단축키는 설정에서 바꿀 수 있다. 기본값이 ZoomIt 과 같으므로 ZoomIt 이 켜져 있으면 겹친다. 브라우저의 Ctrl+숫자(탭 이동)도 막히니 불편하면 Ctrl+Alt+숫자 등으로 바꾸면 된다.

### 그리기 화면 안에서

- 도구: `1` 펜 · `2` 형광펜 · `3` 직선 · `4` 화살표 · `5` 사각형 · `6` 원 · `7`/`T` 글자 · `8` 지우개
- 색: `R` `G` `B` `Y` `O` `P` (Shift+색 = 그 색 형광펜)
- 펜으로 드래그: `Shift` 직선 · `Ctrl` 사각형 · `Ctrl+Shift` 화살표 · `Alt` 원 (ZoomIt 과 동일)
- 형광펜으로 Ctrl/Alt 드래그: 반투명하게 칠한 영역 강조
- 굵기 `Ctrl+휠` 또는 `[` `]` · 확대 `휠`/`↑↓`, `0` 원래 크기, 가운데 버튼 드래그로 이동
- `W` 화이트보드 · `K` 칠판 · `E` 모두 지우기 · `Ctrl+Z`/`Ctrl+Y`
- `Ctrl+S` PNG 저장(사진\MyZoom) · `Ctrl+C` 클립보드 복사
- `Space` 도구 막대 숨기기 · `F1` 도움말 · `Esc`/우클릭 끝내기

### 타이머 화면 안에서

화면 아래 버튼으로 모두 조작할 수 있고, 키로도 된다.

- **제목 바꾸기** `T` (또는 제목을 클릭) → 입력 → `Enter`. 바꾼 제목은 다음 타이머에도 그대로 쓴다
- **다른 화면으로** `Tab` — 모니터가 여러 대면 다음 모니터로 옮긴다 (작은 창 상태에서도 됨)
- `↑↓` 1분 · `←→` 10초 · 휠 1분 · `Space` 일시정지 · `R` 다시 시작 · `Esc` 닫기
- `M` 작은 창: 끌어서 다른 모니터로도 옮길 수 있고, 두 번 클릭하면 그 모니터에서 크게

시간이 끝나면 알림음과 함께 지난 시간이 빨갛게 올라간다. 글자 크기는 모니터 크기에 맞춰 같은 비율로 커진다.

## 개발

```bash
dotnet build                       # 디버그 빌드 → bin/Debug/net9.0-windows/MyZoom.exe
dotnet run                         # 실행
```

자체 렌더링 테스트(디버그 빌드 전용, 화면에 창을 띄우지 않고 주요 화면을 PNG 로 저장):

```bash
bin/Debug/net9.0-windows/MyZoom.exe --selftest <출력폴더>
```

설정 파일: `%APPDATA%\MyZoom\settings.json`, 오류 기록: `%APPDATA%\MyZoom\error.log`.
